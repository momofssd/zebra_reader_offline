# Offline ZPL Label Viewer

A self-contained offline web app that turns Zebra Programming Language (ZPL) into label previews, PNG images, and printable PDFs. Everything runs locally in your browser: no Zebra API, API key, backend server, or internet connection is required.

The app parses ZPL commands, decodes embedded graphic data, and draws the label on an HTML canvas. It also renders Data Matrix, QR, and other supported barcodes, and can decode barcodes from the finished label image.

## Getting started

1. Download [zpl-label-offline.html](zpl-label-offline.html).
2. Open the HTML file in a modern browser, such as Chrome or Edge. No installation or build step is needed.
3. Click **Add a file**, drag a file onto the page, or expand **Type ZPL instead** and paste your ZPL.
4. Adjust the printer resolution, label size, and rotation as needed.
5. Preview your labels, download them, or click **Print**.

The current app accepts one uploaded file at a time. Adding another file replaces the previous file and its previews. A single file can contain multiple labels.

## Supported inputs

| Input | What it must contain |
| --- | --- |
| `.zpl`, `.txt`, `.prn`, `.lbl` | Plain-text ZPL label commands |
| `.pdf` | Extractable text containing ZPL commands |
| Pasted text | ZPL entered under **Type ZPL instead** |

Labels normally begin with `^XA` and end with `^XZ`. PDFs containing only a scanned image or a picture of a label cannot be converted; the app extracts text rather than performing OCR.

## Features

- Preview multiple labels from one ZPL file.
- Render text, boxes, circles, ellipses, diagonal lines, and embedded graphics.
- Decode `^GF` and `~DG` graphic data, including Zebra hex compression, B64, and Z64; recall downloaded graphics with `^XG`.
- Render Code 128, Code 39, Interleaved 2 of 5, EAN-13, EAN-8, UPC-A, QR Code, Data Matrix, and PDF417 barcodes.
- Use **Read barcodes** to inspect barcode types and decoded contents, with their locations highlighted on the label image.
- Download individual labels as PNGs or export labels to PDF, with one label per page.
- Print through the browser's print dialog.

## Settings

| Setting | Behavior |
| --- | --- |
| Printer | Choose 6, 8, 12, or 24 dots per millimeter; the default is 8 dpmm (about 203 dpi). |
| Label size | Read dimensions from `^PW` and `^LL`, or enter a custom size in inches. Missing dimensions fall back to 4 × 6 inches. |
| Rotate view | Rotate by 0°, 90°, 180°, or 270°. The default is 90°; rotation also applies to exported labels. |
| PDF quality | Choose 1×, 2×, or 3× output scale. The default is 2×; this also affects PNG downloads and barcode reading. |
| Honour `^PO I` | Apply upside-down printing when requested by the ZPL. Enabled by default. |
| Size slider | Change the preview card size. |

For printing, select the matching paper size and use 100% / actual-size scaling.

## How it works offline

The HTML file includes its styles, renderer, supporting libraries, and an embedded font. Input files are read in the browser and are not uploaded to a service.

1. Read ZPL directly from a text file, or extract it from a PDF using bundled PDF.js.
2. Parse label commands and decode graphic data locally.
3. Draw text, graphics, and barcodes on a canvas, using bundled bwip-js for barcode generation.
4. Export canvas images as PNG or PDF. Barcode reading uses bundled ZXing to decode the rendered image.

## Rendering notes

The renderer supports a subset of ZPL. Unsupported commands produce warnings, while commands that only control physical printer behavior are ignored. Browser-rendered fonts and layout can differ from a Zebra printer's output.

For QR and Data Matrix fields containing `*/`-separated records, the app reorders the recognized `1J`, `P`, `Q`, `V`, and `1T` records into that sequence when each appears exactly once among the records after the first separator. This changes the encoded barcode contents for matching payloads.

**Read barcodes** reads the rendered image, so its result reflects the barcode generated by the app. It does not guarantee that every barcode will be detected or that a physical printed label will scan successfully.
